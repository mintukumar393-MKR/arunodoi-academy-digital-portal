SECTION D – Short Answer Questions

22. Name any four text properties in CSS.

Answer: text-align, text-indent, text-transform and text-decoration.

23. Which view is used to create the structure of a table in MS Access?

Answer: Design View.

24. What are the different values you can provide with the text-transform property?

Answer: none, capitalize, uppercase and lowercase.

25. What does the text-indent property do?

Answer: It specifies the indentation of the first line of a paragraph or text.

26. What is the use of the border-collapse property?

Answer: It specifies whether table cell borders should be collapsed into a single border or kept separate.

27. Name the three main border properties.

Answer: border-width, border-style and border-color.

28. Name the property used to set the thickness of the border.

Answer: border-width.

29. Which CSS property is used to apply underline, overline, or line-through to text?

Answer: text-decoration.

30. Which property is used to set the spaces between the table cells?

Answer: border-spacing.
SECTION E – Answer any FIVE Questions

1. State the importance of a Definition List. Name the three tags used in it.

Answer: A Definition List is used to display terms along with their definitions or descriptions.

Three tags:
<DL> – Definition List
<DT> – Definition Term
<DD> – Definition Description

2. What is the use of the font shorthand property? Write its syntax.

Answer: The font shorthand property is used to specify several font properties in a single declaration.

Syntax:

selector { font: style weight size family; }

3. What is the difference between Datasheet View and Design View in MS Access?

Answer: Datasheet View: Used to enter, edit and view data in a table.

Design View: Used to create or modify the structure of a table, such as field names, data types and primary key.

4. Write a short note on Nested Lists.

Answer: A Nested List is a list placed inside another list. It is used to create sub-items or subcategories within a main list.

5. Differentiate between <TH> and <TD>.

Answer:
<TH> <TD>
Defines a table heading cell. Defines a table data cell.
Generally displayed bold and centred by default. Contains ordinary table data.

6. What does the text-transform property do?

Answer: The text-transform property is used to change the capitalization of text. Its values include: uppercase, lowercase, capitalize and none.

7. What is a primary key? State its use in a table.

Answer: A primary key is a field that uniquely identifies each record in a table. It does not allow duplicate or Null values.

8. What is CSS?

Answer: CSS stands for Cascading Style Sheets. It is used to control the appearance and formatting of HTML elements on a web page.

9. Differentiate between <UL> and <OL> tags.

Answer:
<UL> <OL>
Creates an unordered list. Creates an ordered list.
Items are normally displayed with bullets. Items are displayed with numbers or letters.
